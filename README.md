# Personal Portfolio Website

This is my personal portfolio website created using **HTML** and **CSS**. The website showcases my profile, skills, projects, education details, and contact information in a simple and responsive design.

## Features

* Clean and modern user interface
* Responsive layout
* About Me section
* Skills section
* Projects showcase
* Contact information
* Easy navigation

## Technologies Used

* HTML5
* CSS3

## Purpose of the Project

The main purpose of this project is to improve my frontend web development skills and create an online portfolio to showcase my work and achievements.
